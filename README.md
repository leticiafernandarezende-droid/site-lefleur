# Loja Virtual - Buquês de Flores de Cetim

## Descrição do Tema
Este projeto consiste no desenvolvimento de um site de comércio eletrônico (E-commerce) voltado para a venda de **buquês de flores de cetim artesanais**. O sistema permite que os clientes naveguem pelo catálogo de buquês personalizados, visualizem detalhes essenciais como **tamanhos, cores disponíveis, valores e quantidade**, facilitando a escolha e a compra de arranjos duráveis para ocasiões especiais.

## ⚙️ Instruções de Execução Local

Siga o passo a passo abaixo para rodar o projeto na sua máquina usando o XAMPP:

### 1. Pré-requisitos
* Ter o [XAMPP](https://www.apachefriends.org/pt_br/index.html) instalado no seu computador.

### 2. Configurando o Código-Fonte
1. Baixe ou clone este repositório.
2. Copie a pasta principal do projeto.
3. Cole a pasta dentro do diretório raiz do servidor web do XAMPP (geralmente localizado em `C:\xampp\htdocs\` no Windows).

### 3. Configurando o Banco de Dados
1. Inicie o painel de controle do XAMPP e dê o **Start** nos módulos **Apache** e **MySQL**.
2. Abra o seu navegador e acesse o phpMyAdmin: `http://localhost/phpmyadmin/`
3. Crie um novo banco de dados (ex: `db_buques_cetim`).
4. Clique na aba **Importar**, selecione o arquivo do banco de dados (`.sql`) que está localizado dentro da pasta do projeto e clique em **Executar**.

### 4. Acessando o Projeto
1. Abra o navegador e digite o endereço: `http://localhost/buques/index.php`
2. Pronto! O site da loja de buquês de cetim já estará rodando e pronto para uso.
